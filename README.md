# Coffee Sales Analysis Dashboard (Excel)

An interactive Excel dashboard analyzing coffee shop sales transactions — 
built entirely with Excel PivotTables, PivotCharts, and Slicers (no Power BI).

## 📊 Data Source
Dataset from Kaggle (coffee shop transaction records, 2024-2025).

## 🎯 Key Metrics
| Metric | Value |
|---|---|
| Total Revenue | ₹1,12,245.58 |
| Total Orders | 3,547 |
| Average Order Value | ₹31.65 |

## 💡 Key Insights
- **Latte** and **Americano** are the top-selling coffee types by volume
- **Afternoon** is the busiest time of day (34% of sales)
- **Tuesday** sees the highest single-day revenue
- Clear seasonal spike in revenue around May-June 2024

## 🛠️ Built With
- Microsoft Excel — PivotTables, PivotCharts, Slicers, conditional formatting

## 📁 Files
- `Coffee_Sales_Dashboard.xlsx` — Interactive dashboard
- `COFFE_SALES_CLEAN_DATA.csv` — Cleaned transaction data
